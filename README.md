# 다온 헬스케어 (DAON Healthcare) — 해커톤 시연용 웹 프로토타입

**장애인·고령층의 복약 · 진료 · 돌봄 연계 AI 도우미.** 약봉투를 읽어 오늘의 약을 정리하고, 시간에 맞춰 알리고, 안부 전화로 컨디션을 확인해 보호자·돌봄 인력에게 전해 줍니다.

> **`hackathon` 브랜치 전용입니다.** `main` 브랜치는 다른 공모전용 **장애인 일자리 AI 카운셀러**이며 GitHub Pages로 배포 중입니다(https://mingun0729-jpg.github.io/daon-counselor/). 이 브랜치는 그 화면을 건드리지 않고, 같은 디자인·채팅·음성·OCR·알림 구조를 헬스케어로 다시 쓴 것입니다.

- 대회: **2026 마산대학교 X 연암공과대학교 AI 헬스케어 해커톤** (1박 2일 · 마산대 보건 + 연암공대 공학)
- 참여 주제: 안내자료 **01 복약 안전 · 08 돌봄 대화 · 10 방문 돌봄 연계** 결합
- 워크북·발표 초안: **[`docs/hackathon-plan.md`](docs/hackathon-plan.md)**
- 서버·설치 없음. `index.html` 한 파일로 동작합니다.

| 화면 | 하는 일 | 시연 포인트 |
| --- | --- | --- |
| **💬 다온 채팅** (첫 화면) | 인사, 오늘의 복약·돌봄 브리핑, 빠른 질문, **말로 입력(음성 인식)**, 약봉투 사진 버튼 | "오늘 먹을 약 알려줘" → 약 목록 카드 / **"가슴이 아파요" → 119 안내**(진단하지 않음) |
| **💊 오늘의 약** | 가상 인물 카드, 오늘 복약 진행률, 아침·점심·저녁·자기 전 시간대별 약 체크, **약봉투 읽기** | 사진(또는 예시 약봉투) → **글자 읽기** → 확인·수정 → **오늘 일정에 넣기** → 체크하면 진행률 상승 |
| **📞 안부 전화** | 다온이 거는 **인터넷 음성 통화 시연** · 시나리오 3종(복약·컨디션·병원) | 통화 → **3줄 정리 + `DAON-CALL-YYYY-NNNN`** → **보호자에게 전달** → 알림 센터에 기록 |
| **🔔 맞춤 알림** | 휴대폰 알림 권한, 받을 소식 5개 스위치, 병원·복지 연계, 알림 센터 | 소식을 끄면 그 알림이 사라짐 / 병원 예약·보건소 연계 알림 추가 |

- 아래에 **안전 고지 줄**이 고정: "가상 데이터 시연용 · 다온은 진단·처방을 대신하지 않아요. 응급 상황은 119."
- **편하게 보기**: 큰 글씨 · 고대비 · 읽어주기(속도 조절)
- 모든 이름·약·병원은 **가상(가명)**. 이름·연락처를 입력받는 칸이 없습니다.

## 2. 시연 방법 (3분)

1. 화면을 열고 **가상 데이터로 시작하기**를 누릅니다(첫 실행 안전 안내).
2. **💊 오늘의 약** → `예시 약봉투로 해 보기` → 읽는 화면 → **결과 확인**(새 약 2종 + 이미 먹던 약 1종은 건너뜀) → **오늘 일정에 넣기**.
3. 시간대 카드의 **○를 눌러 ✓로** 바꿉니다 — 오늘 복약 진행률이 올라갑니다.
4. **📞 안부 전화** → `복약 확인` → 답변 칩을 눌러 대화 → **정리 카드** → `보호자에게 전달 (시연)`.
5. **🔔 맞춤 알림** → 알림 센터에 전달 기록과 병원·복지 연계 알림이 쌓인 것을 확인.
6. **💬 다온 채팅**으로 돌아와 **"가슴이 아파요"** 입력 → 119 안내(안전 경계)로 마무리.

**인터넷이 없을 때**: 예시 약봉투 경로는 CDN 없이 그대로 동작합니다(사진 OCR만 인터넷 필요).
**소리가 안 날 때**: 모든 대사가 자막으로 남습니다. `읽어주기`를 켜면 다온이 말로 안내합니다.

| **시연(가상)** | 인물·약·병원·보건소·보호자, `DAON-CALL` 정리 번호, 보호자 전달, 병원·복지 연계 알림 |
