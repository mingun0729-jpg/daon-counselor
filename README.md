# 다온(DAON) — 장애인 일자리 맞춤형 AI 카운셀러 (프로토타입)

장애 당사자가 몇 번의 선택만으로 **신청 가능한 일자리·지원제도**를 판별하고, **맞춤 근무지**와 **준비 서류**, **신청서 초안**까지 한 번에 정리해 주는 AI 카운셀러 화면입니다. 공모전 시연을 위해 실제 업무 흐름을 화면으로 옮긴 단일 HTML 프로토타입입니다.

## 주요 기능

1. **일자리·지원제도 판별** — 장애 정도, 장애 유형, 희망 근무형태(전일제·시간제·복지형·재택), 근무 환경 조건을 차례로 고르면 신청 가능한 사업을 조건과 함께 보여 줍니다.
2. **맞춤 근무지** — 근무 환경 조건(휠체어 접근, 장시간 서있기 어려움, 단순·반복 사무 선호, 의사소통 지원 필요 등)에 맞춰 근무지 예시를 매칭 원리와 함께 제시합니다.
3. **서류·신청서** — 사업별로 필요한 준비 서류를 정리하고, 입력한 조건에 맞춘 신청서 초안을 만들어 줍니다.
4. **대화형 상담** — 위 4단계를 채팅 형식으로도 진행할 수 있고, 화면 오른쪽(모바일에서는 하단)에 단계별 결과가 쌓입니다.

## 시연 방법

첫 화면의 **예시 버튼 3개** 중 하나를 누르면 상담이 조건 선택부터 결과 정리까지 자동으로 끝까지 진행됩니다.

- 지체·심한 장애 / 휠체어 이용 / 주 14시간 희망
- 지체·심하지 않은 장애 / 전일제 사무 / 서서 일하기 어려움
- 청각·심한 장애 / 수어·문자통역 필요 / 주 20시간

첫 화면에서 **직접 입력**으로 자기 조건을 하나씩 선택해 진행할 수도 있습니다.
