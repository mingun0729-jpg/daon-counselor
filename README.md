# 다온(DAON) — 장애인 일자리 도우미

복지카드 한 장으로 **할 수 있는 일자리를 찾고**, 나라 기관에 필요한 **서류를 대신 받아 오고**, **신청서까지 내는** 장애인 일자리 맞춤형 AI 도우미의 공모전 시연용 웹 프로토타입입니다.

- 시연 링크: **https://mingun0729-jpg.github.io/daon-counselor/**
- 출발점: 진주시지체장애인협회 일자리 업무 현장 경험(작성자 본인 근로 경험)
- 서버·설치 없음. `index.html` 한 파일로 동작하며, 외부 라이브러리를 쓰지 않습니다.

## 1. 앱처럼 이어지는 네 화면

상담 질문을 길게 주고받던 단계는 없앴습니다. 화면마다 **지금 눌러야 할 큰 버튼 하나**만 두었습니다.

| 화면 | 무엇을 하나요 | 큰 버튼 |
| --- | --- | --- |
| **1. 복지카드** | 카드를 찍거나 올리면 장애 유형·정도를 읽습니다. 카드가 없으면 예시 카드 3종으로 해 볼 수 있어요. | `복지카드 찍기·올리기` · `예시 카드로 해보기` |
| **2. 할 수 있는 일자리** | 복지카드 조건으로 **신청할 수 있어요 / 확인해 보세요 / 지금은 어려워요**를 나눠 보여 주고, 진주에서 일할 수 있는 곳을 함께 골라 줍니다. | `이 일자리로 서류 준비하기` |
| **3. 서류** | 다온이 정부24·국민건강보험공단·복지로·고용24에 **대신 로그인해서** 서류를 받아 오고 **신청서에 붙입니다.** 접속 → 로그인 → 발급 → 첨부 과정이 실시간 로그로 보입니다. | `한 번에 로그인하고 N장 가져오기` |
| **4. 신청** | 복지카드와 기관 서류로 채운 칸은 그대로 두고, **빠진 칸만** 적습니다(연락처·사는 곳·계좌·하고 싶은 말). | `신청서 내기` → 접수번호 `DAON-2026-XXXX` |

- 접수증에는 접수번호·접수처·신청한 일·일할 곳·함께 낸 서류·접수 시각이 나오고, **신청서 인쇄**, **서류 모두 저장(ZIP)**, **메일로 보내기**를 할 수 있습니다.
- 하던 곳은 브라우저에 자동 저장되어, 창을 닫았다 열어도 이어서 할 수 있습니다. `처음부터`로 초기화합니다.

## 2. 장애인 특성을 고려한 화면

- **큰 버튼·넉넉한 여백·짧은 문장**: 한 화면에 핵심 한 가지, 버튼은 56~62px(큰 글씨 모드 64~72px).
- **쉬운 말**: "복지카드 찍기", "할 수 있는 일자리", "나라에서 서류 가져오기", "빠진 것만 적고 내기".
- **편하게 보기 3버튼** (화면 위, 늘 보이는 자리):
  - `글씨 크게` — 본문 20px 이상, 버튼 64px 이상
  - `고대비` — 검은 배경·밝은 글씨로 대비를 높임
  - `읽어주기` — 화면을 한국어 음성으로 읽어 줌 (기본 속도 **0.82 천천히**, 0.93 보통 선택)
- **장애 유형별 자동 배려**: 카드를 읽으면 유형에 맞춰 화면을 맞춥니다.
  - 지체·뇌병변 → 큰 버튼, 짧은 화면
  - 시각 → 큰 글씨 + 읽어주기 자동 켜기
  - 청각 → 모든 안내를 글로 크게
  - 발달 → 쉬운 말 모드(한 번에 하나씩, 긴 설명 접기)
- 키보드·스크린리더를 위한 `aria-*`, 본문 바로가기, 포커스 표시, 움직임 줄이기 설정 대응.

## 3. 시연 방법 (1분)

1. `예시 카드로 해보기` → **지체장애 · 심한 장애**(김다온, 가명) 선택
2. 카드를 읽는 4단계 연출 → `할 수 있는 일자리 보기`
3. 조건에 맞는 일자리 3개와 진주 근무지 확인 → 하나 고르고 `이 일자리로 서류 준비하기`
4. `한 번에 로그인하고 4장 가져오기` → 인증 방법(카카오·네이버·공동인증서·아이디) 고르고 `시연 인증하고 서류 가져오기`
   - "정부24에 접속하고 있어요 → 로그인 완료 → 주민등록등본 서류를 받았어요 → 신청서에 붙였어요" 로그가 차례로 쌓입니다
   - 서류는 실제 파일 카드(파일명·발급기관·크기·`미리보기`·`저장`)로 표시되고 `신청서에 자동 첨부됨` 배지가 붙습니다
5. `빠진 것만 적으러 가기` → 연락처·사는 곳·계좌 입력, `AI가 초안 써 주기`로 자기소개 작성
6. `신청서 내기` → 접수번호가 나오고 인쇄·ZIP 저장·메일 보내기

다른 예시: **청각장애 · 심하지 않은 장애**, **발달장애 · 심한 장애**(쉬운 말 모드).

## 4. 무엇이 시연이고 무엇이 진짜인가

| 구분 | 내용 |
| --- | --- |
| 시연(가상) | 복지카드 OCR, 기관 로그인·간편인증, 서류 자동 수집·첨부, 접수, 접수증, 서류 파일 내용 |
| 실제 정보 | 접수처 **(사)경남지체장애인연합회 진주시지회**의 기관명·주소·대표전화(055-755-0008) |
| 실제 기준 | 2026년 장애인일자리 사업안내(보건복지부)의 사업 종류·근무시간·보수 |
| 가상 값 | 신청인 이름·연락처·주소·계좌·경력 등 모든 개인 정보는 가명·예시 |

- 카드 사진은 **서버로 전송되지 않습니다.** 사진을 올려도 실제로 읽지 않고, 시연용 예시 값으로 채운 뒤 `고치기`로 바꾸도록 안내합니다.
- 기관 로그인은 **실제 아이디·비밀번호를 넣지 않는** 원클릭 시연입니다. 어떤 정보도 외부로 보내지 않습니다(외부 요청 0건).
- 만들어진 서류 파일은 브라우저 안에서만 생성되는 **가상 문서**이며, 실제 발급 효력이 없습니다. 실제 신청은 협회 담당자 안내에 따라 본인이 서류를 준비·서명해야 합니다.

## 5. 파일과 배포

```
index.html    # 프로토타입 전체 (배포본)
README.md     # 이 문서
CLAUDE.md     # 구조·규칙 (AI 에이전트·사람 공용)
.nojekyll
```

- `main` 브랜치에 push하면 GitHub Pages가 자동 반영합니다(1분 내외).
- 로컬 원본은 `prototypes/disability-job-counselor.html`이며 배포 전 `index.html`과 동일하게 맞춥니다(MD5).
- 접근성 설정은 `daon.a11y.v1`, 진행 상태는 `daon.state.v1`(스키마 v4)로 브라우저에만 저장됩니다.
