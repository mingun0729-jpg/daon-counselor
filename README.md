# 다온(DAON) — 장애인 일자리 맞춤형 AI 카운셀러 (프로토타입)

장애 당사자가 **복지카드(장애인등록증)를 찍는 것에서 시작해** 신청 가능한 일자리·지원제도를 판별하고, **맞춤 근무지**·**구비서류**·**참여신청서 작성**까지 한 번에 끝내는 AI 카운셀러 화면입니다. 공모전 시연을 위해 실제 업무 흐름을 화면으로 옮긴 단일 HTML 프로토타입입니다.

## 주요 기능

1. **복지카드 촬영·업로드 → 자동 인식 (시연)** — 상담 패널 위 **📷 복지카드 촬영·업로드**로 사진을 올리거나, **🎬 샘플 1(지체·심한) / 샘플 2(청각·심한)** 버튼으로 1클릭 시연.
   - ① 카드 테두리·보안 마스킹 확인 → ② 장애유형·장애정도·성명 추출 → ③ 추출 결과 확인·수정 → ④ 상담 조건 & 신청서 1단계 자동 입력까지 4단계로 진행됩니다.
   - 업로드한 사진은 브라우저 안에서만 미리보기로 쓰이며 **서버로 전송되지 않습니다**. (실제 OCR 대신 시연용 가상 값을 보여 주는 연출입니다.)
2. **일자리·지원제도 판별** — 장애 정도, 장애 유형, 희망 근무형태(전일제·시간제·복지형·재택), 근무 환경 조건을 고르면 신청 가능한 사업 8종을 조건과 함께 보여 줍니다. 근로지원 제도 7종도 함께 안내합니다.
3. **맞춤 근무지** — 근무 환경 조건(휠체어 접근, 장시간 서있기 어려움, 단순·반복 사무 선호, 의사소통 지원 필요 등)에 맞춰 근무지 예시 10곳을 매칭 원리와 함께 제시합니다.
4. **신청서 작성 4단계 (탭 ③)** — 실제 **장애인일자리사업 참여신청서** 흐름을 그대로 따라갑니다.
   - **Step 1. 기본정보·장애정보 확인** — 복지카드 인식값(성명 가명·장애유형·장애정도) 자동 채움 + 연락처·거주지 수정
   - **Step 2. 희망 사업·근로여건** — 판별된 사업 자동 연결 + 1·2지망 직무, 이동수단(자차/대중교통/특별교통수단 등), 필요 편의지원(휠체어 접근·근로지원인·보조공학기기 등) 선택
   - **Step 3. 지원동기·자기소개** — 조건 기반 AI 초안 자동 생성 / 다른 표현으로 재생성 / 직접 수정
   - **Step 4. 구비서류 체크 & 최종 점검** — 완료 배지(예: `기본정보 완료 · 서류 3/8 확인됨`), 누락 서류 자동 점검, **신청서 전체 미리보기 · 텍스트 복사 · 인쇄용 출력**
   - 미리보기·인쇄 양식에 **신청일, 접수처, 구비서류 준비 현황 표, 개인정보 수집·이용 동의 확인, 신청인 서명란(`(서명 또는 인)`)** 을 넣어 실제 참여신청서와 가깝게 구성했습니다. (시연용 고지·제출 전 실제 양식 확인 안내는 유지)
   - **원클릭 자동 접수 시연** — 4단계 하단 `진주시 지체장애인협회로 자동 접수 시연` 버튼을 누르면 ① 구비서류·필수 입력 항목 자동 점검(부족한 항목은 ‘보완하기 / 그대로 진행’ 선택) → ② 신청서 패키지 생성 → ③ 협회 접수 시뮬레이션 전송 → ④ **시연용 가상 접수증**(`DAON-2026-XXXX`, 접수 일시, 신청 사업, 접수처, 인쇄) 순서로 진행됩니다. 실제 기관으로는 전송되지 않습니다.
   - **이메일로 바로 보내기(메일 앱 열기)** — 빈 수신자 `mailto:`로 제목(`[장애인일자리 참여신청] 홍길동 - 사업명`)과 본문(신청서 요약 + 첨부 안내)을 자동으로 채워 메일 앱을 열어 줍니다. 담당자 메일 주소만 넣으면 발송할 수 있고, 메일 앱이 없으면 본문 복사로 대신합니다.
   - **서면 접수 안내** — 인쇄(PDF 저장) 후 신분증·복지카드를 지참해 방문하는 방법을 4단계와 접수 가이드에 함께 적어 두었습니다.
5. **필요서류 자동 수집 에이전트 (시연용 Mock API)** — 서류 탭 체크리스트 상단과 자동 접수 시연 1단계에 `🤖 필요서류 자동 수집 (예시 API)` 버튼이 있습니다. 누르면 서류별로 발급기관 API 요청 → 응답(발급기관·시연용 발급번호·상태 배지)을 순차로 보여 주고, 수집된 서류를 구비서류 체크리스트와 신청서 서류 표에 자동으로 체크합니다. 코드의 `MockDocAgentAPI.fetchDocument` 한 곳만 `fetch()`로 바꾸면 실제 백엔드·공공 API로 교체할 수 있는 구조이며, 지금은 **외부 요청 0건의 모의(Mock) 응답**입니다.
   - **서류 파일 카드** — 수집된 서류는 텍스트 나열 대신 **실제 파일 카드**로 표시됩니다. 파일명(`01_장애인일자리_참여신청서_김다온.html`, `05_복지카드_사본_김다온.svg` 등), 생성된 Blob의 실제 바이트 수(`9.3 KB`), 파일 형식(HTML/SVG), 발급처, `시연용 생성됨` 배지가 붙고, 카드마다 **미리보기**·**저장**(44px 이상) 버튼이 있습니다.
   - **파일 미리보기** — 카드의 `미리보기`를 누르면 모달에서 그 파일의 실제 내용을 그대로 봅니다. 신청서·참여자 정보 확인서·개인정보 동의서, 주민등록등본·건강보험 자격득실확인서 표, 복지카드·신분증 사본(SVG 이미지)까지 서식 그대로이며, 모두 ‘시연용 가상 문서’ 워터마크와 고지가 들어갑니다. 모달에서 **인쇄**도 할 수 있습니다.
   - **파일 저장** — `저장`은 순수 JS `Blob` + `URL.createObjectURL`로 **실제 HTML/SVG 파일**을 내려받습니다(외부 라이브러리 0개, 오프라인 동작). 내려받은 HTML은 브라우저에서 바로 열리고 인쇄할 수 있습니다.
   - **ZIP 패키지** — 자동 접수 시연 2단계에서 서류가 하나씩 순차로 생성되어 `신청서_제출패키지_김다온.zip`(무압축 ZIP, 실제로 열림)으로 묶입니다. 진행률·파일 수·패키지 크기가 표시되고, 개별 저장과 **패키지 저장(ZIP)** 이 모두 동작합니다.
6. **접근성 모드 (헤더 툴바)** — `큰 글씨` · `고대비` · `음성 안내` 토글과 `화면 읽기` · `정지` 버튼.
   - **큰 글씨**: 본문 22px, 말풍선 20px, 버튼·칩·입력 최소 높이 56px로 키우고 1280px·375px 모두에서 가로 스크롤이 생기지 않게 맞췄습니다.
   - **고대비**: 어두운 배경 + 최대 명도 대비 테마 (텍스트·배지·버튼·파일 카드 4.5:1 이상)
   - **음성 안내**: 브라우저 내장 `speechSynthesis`로 민원인에게 말하듯 부드러운 구어체 대본(‘안녕하세요, 다온입니다. …’)을 읽어 줍니다. 한국어 음성은 SunHi·Yuna·Sora·Heami·Google 한국의 순으로 자연스러운 것을 고르고 `rate 0.93`·`pitch 1.04`로 천천히 부드럽게 읽으며, `정지`로 멈춥니다. 미지원 브라우저에서는 안내 토스트로 대체
   - 큰 글씨·고대비·음성 안내 설정은 `localStorage`에 저장되어 다음 방문에도 유지됩니다.
7. **자동 임시저장·복원** — 상담 조건, 서류 체크, 신청서 4단계 입력값(성명·연락처·거주지·직무·이동수단·편의지원·자기소개)을 브라우저 `localStorage`에 자동 저장하고, 새로고침·재방문 시 그대로 복원합니다. 저장 상태(`자동 저장됨 14:32`)를 화면에 표시하며, `조건 다시 고르기`·예시 버튼으로 새로 시작하면 함께 비웁니다. 저장값은 서버로 전송되지 않습니다.
8. **실제 신청·접수 가이드 (탭 ③)** — 집중 모집 시기(보통 매년 11월 말~12월 초 차년도 모집), **기본 접수처 (사)경남지체장애인연합회 진주시지회**(진주시 지체장애인협회 · 경남 진주시 대신로 232번길 16 · ☎ 055-755-0008), 진주시가 직접 접수하는 일반형(전일제·시간제)·복지일자리 참여형과 수행기관 별도 모집(특수교육-복지연계형·특화형)의 구분, 7단계 진행 순서, 면접·선발 체크 팁, 입력한 거주지 기준 접수처 안내. 신청서 미리보기·인쇄·텍스트 복사에도 같은 기관명·주소·전화와 ‘… 귀하’ 수신 문구가 들어갑니다.
9. **서류 체크리스트 & 초안** — 사업별 구비서류와 발급처를 정리하고, 자기소개·지원동기 5항목 초안을 만들고 복사할 수 있습니다.
10. **대화형 상담** — 4단계를 채팅으로도 진행할 수 있고, 화면 오른쪽(모바일에서는 아래)에 단계별 결과가 쌓입니다.

## 시연 방법

**① 복지카드로 시작 (권장)**

1. 상담 패널 위 **📷 복지카드 촬영·업로드**를 누르거나, **🎬 샘플 1 시연**을 누릅니다.
2. 4단계 인식이 자동으로 진행되고, ③에서 추출값을 확인·수정한 뒤 **이 내용으로 시작**을 누릅니다.
3. 상담에서 남은 질문(근무형태·환경)에 답하면 판별이 끝납니다.
4. **서류·신청서** 탭에서 **신청서 작성 4단계**를 따라가면 미리보기·복사·인쇄까지 됩니다.
5. 체크리스트 위 **🤖 필요서류 자동 수집 (예시 API)** 로 서류를 한 번에 받아 오는 시연을 하고, 4단계 하단 **진주시 지체장애인협회로 자동 접수 시연**을 누르면 점검 → 패키지 → 접수 → **가상 접수증**까지 한 번에 흘러갑니다. **이메일로 바로 보내기(메일 앱 열기)** 로 메일 초안도 바로 만들 수 있습니다.

**② 예시 버튼으로 바로 시작**

첫 화면의 **예시 버튼 3개** 중 하나를 누르면 상담이 조건 선택부터 결과 정리까지 자동으로 끝까지 진행됩니다.

- 지체·심한 장애 / 휠체어 이용 / 주 14시간 희망
- 지체·심하지 않은 장애 / 전일제 사무 / 서서 일하기 어려움
- 청각·심한 장애 / 수어·문자통역 필요 / 주 20시간

첫 화면에서 **직접 입력**으로 자기 조건을 하나씩 선택해 진행할 수도 있습니다.
