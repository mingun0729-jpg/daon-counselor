🧭인식 단계

① 카드 확인 → ② 정보 추출 → ③ 결과 확인 → ④ 상담·신청서 자동 입력 순서로 진행됩니다.

    🔒사진은 서버로 전송되지 않습니다. 이 화면은 공모전 시연용으로, 실제 OCR 대신 브라우저 안에서 미리 준비한 예시 값을 보여 줍니다. 이름은 가명으로 처리해요.

    📨

    진주시 지체장애인협회로 자동 접수 시연

    서류 점검 → 신청서 패키지 → 접수 시뮬레이션 → 가상 접수증

    🧭자동 접수 단계

    ① 서류·입력 항목 점검 → ② 신청서 패키지 생성 → ③ 협회 접수 시뮬레이션 → ④ 가상 접수증 발급 순서로 진행됩니다.

      🔒실제 기관으로 전송되지 않습니다. 이 화면은 공모전 시연용으로, 서버 없이 브라우저 안에서 접수 과정을 흉내 내고 시연용 가상 접수증을 만들어 줍니다. 신청서와 입력값은 이 브라우저 밖으로 나가지 않습니다.
